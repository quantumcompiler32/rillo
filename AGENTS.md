# Rillo agent guidance

Rillo helps Milpitas Middle College students plan college courses and understand possible degree progress. Treat all degree results as planning estimates until an official college evaluation confirms them. Never infer that a planned course awards credit.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `quantumcompiler32/rillo`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. Read `CONTEXT.md` and relevant ADRs in `docs/adr/` when present. See `docs/agents/domain.md`.

## Commits

When building Rillo, make frequent, small commits at meaningful, reviewable milestones rather than bundling the work into one large commit. Keep unrelated changes separate, validate each milestone as appropriate, and do not include pre-existing user changes without authorization.
